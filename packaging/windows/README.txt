W-Feature — 피처폰 게임 에뮬레이터 (Windows)


1. 압축 풀기

   압축을 푼 폴더째 원하는 곳에 배치한다.


2. 게임 넣기

   games 폴더 안에 게임 파일을 넣는다. 자세한 건 games\README.txt 문서 확인.


3. 실행

   start.bat 를 더블클릭한다. 
   검은 창이 하나 뜨고 잠시 뒤 브라우저에서 http://127.0.0.1:11541 이 열린다.

   ** 처음 한 번은 두 가지 창이 뜰 수 있다. **

   - "Windows의 PC 보호" 파란 창: 
     - 서명된 프로그램이 아니어서 발생.
     - [추가 정보] → [실행]을 누른다.
   - 방화벽 허용 창: 
     - 폰에서 접속하려면 [개인 네트워크]에 체크하고 허용.
     - 이 PC에서만 쓸 거면 허용하지 않아도 된다.

   서버를 멈추려면 그 창에서 Control-C 를 누른다. 
   검은 창을 닫아도 멈추지만 인게임 마지막 저장 데이터가 유실될 수 있다.

   창을 이미 닫아버렸거나 예전에 띄운 서버가 남아 있으면 이 둘을 더블클릭한다.

       status.bat               지금 떠 있는지, 몇 번 포트인지
       stop.bat                 중지


4. 접속

   서버는 http, https 두 주소를 함께 연다.
   게임패드를 사용하거나 음악이 밀릴 경우 https 주소로 접근해야한다.

       http://<IP>:11541        경고 없음. 음악이 밀릴 수 있고 게임패드 사용 불가능.
       https://<IP>:11641       첫 접속 때 인증서 경고 1회.

   IP: 서버 창의 "open from another device" 줄, 또는 status.bat 출력.
   예: http://192.168.0.1:11541, https://192.168.0.1:11641
   에뮬레이터 설정(키패드 배치, 음량 등)이 두 주소 간 공유되지 않는다.
   설정을 옮기려면 게임 선택 화면의 [백업] 기능을 사용한다.

   로컬호스트의 경우 http 접속이라도 음악이 밀리지 않고 게임패드 사용이 가능하다.

   ** https 첫 접속 경고 **

   - "연결이 비공개로 설정되어 있지 않습니다" 같은 경고:
     - 서버가 직접 만든 인증서여서 발생.
     - Chrome·Edge (PC, 안드로이드): [고급] → 아래의 "(안전하지 않음)" 링크
     - Firefox: [고급...] → [위험을 감수하고 계속]
     - Safari (Mac, iPhone): [세부사항 보기] → [이 웹 사이트 방문]. Mac은 확인 창과 암호 입력이 이어질 수 있다.

   ** 포트 바꾸기 **

   기본적으로 https 포트는 http 포트 + 100번으로 매핑된다.

       wfeature-server.exe -addr :11542                http 11542, https 11642
       wfeature-server.exe -https 11700                https 만 11700
       wfeature-server.exe -https off                  https 끄기
       wfeature-server.exe -addr 127.0.0.1:11541       로컬호스트에서만 허용

   기본 설정이면 같은 네트워크의 누구나 접속할 수 있다.
   브라우저에서 "홈 화면에 추가"를 하면 앱처럼 쓸 수 있다.


5. 폴더 구성

   wfeature-server.exe          서버 
   start.bat                    더블클릭용 실행 파일
   stop.bat                     멈추기
   status.bat                   떠 있는지 확인
   games\                       게임을 넣는 곳
   ext\                         화면의 "＋ 게임 추가"로 넣은 게임
   savedata\                    세이브
   tls\                         https 인증서. 지우면 다음 실행 때 새로 만든다.
   logs\                        디버그 기록 (디버그 빌드에서만 생김)

   서버를 업데이트할 때는 wfeature-server.exe 만 새 버전으로 교체하면 된다.


6. 자주 막히는 곳

   - 방향키가 안 먹는 경우:
     - 키패드 타입을 바꾸거나 커스텀한다.
   - 포트가 이미 쓰이는 경우:
     - status.bat 으로 wfeature 서버인지 다른 프로그램인지 본다.
     - stop.bat 으로 멈추고 포트를 바꿔 띄운다.
   - https 주소만 안 열리는 경우:
     - 서버 창에 "serving without HTTPS" 가 있으면 해당 포트를 다른 프로세스가 점유 중.
     - https 포트를 다른 포트로 옮긴다.
   - 목록에 게임이 안 보이는 경우:
     - 확장자가 .zip 또는 .jar 인지, games\ 또는 그 바로 아래 폴더에 들어 있는지 확인한다.
