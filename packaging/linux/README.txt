W-Feature — 피처폰 게임 에뮬레이터 (Linux)


1. 압축 풀기

   압축을 푼 폴더째 원하는 곳에 둔다.


2. 게임 넣기

   games 폴더 안에 게임 파일을 넣는다. 자세한 건 games/README.txt 문서 확인.


3. 실행

   압축을 푼 폴더에서 실행한다. 데스크톱 환경이면 잠시 뒤 브라우저에서
   http://127.0.0.1:11541 이 열린다.

       ./start.sh

   ** 처음 한 번 막히는 곳은 둘이다. **

   - 실행 권한이 없다는 경고:
     - 아카이브에서 권한이 떨어져 나간 경우 발생.
     - 한 번만 이렇게 준다.

       chmod +x start.sh stop.sh status.sh wfeature-server

   - 브라우저가 저절로 열리지 않는 경우:
     - SSH 같은 원격 접속이라 띄울 화면이 없어서 발생.
     - 위 주소를 직접 연다.

   서버를 멈추려면 Control-C 를 누른다.

   창을 이미 닫아버렸거나 예전에 띄운 서버가 남아 있으면 이 둘을 실행한다.

       ./status.sh              지금 떠 있는지, 몇 번 포트인지
       ./stop.sh                멈추기

   포트를 옮겨 띄웠으면 뒤에 포트를 붙인다 (./stop.sh 11542).
   그 포트에 있는 것이 wfeature 서버가 아니면 건드리지 않고 알려만 준다.


4. 휴대폰으로 접속

   같은 네트워크에 있는 폰의 브라우저에서 이 컴퓨터의 주소로 연다.
   주소는 터미널에 뜨는 URL이거나, ip addr 를 치면 나오는 IP 주소다.
   예: http://192.168.0.5:11541

   같은 네트워크에 있는 사람은 누구나 게임 목록을 보고 세이브를 읽고 쓸 수 있다.
   이 컴퓨터에서만 쓰려면 이렇게 띄운다.

       ./wfeature-server -addr 127.0.0.1:11541

   브라우저에서 "홈 화면에 추가"를 하면 앱처럼 쓸 수 있다.


5. 폴더 구성

   wfeature-server              서버 (이 파일 하나에 화면·글꼴이 다 들어 있다)
   start.sh                     실행 스크립트
   stop.sh                      멈추기
   status.sh                    떠 있는지 확인
   games/                       게임을 넣는 곳
   savedata/                    세이브 (처음 저장할 때 생긴다)
   logs/                        디버그 기록 (설정에서 저장을 눌렀을 때만)

   서버를 업데이트할 때는 wfeature-server 만 새 것으로 바꾸면 된다.
   games/ 와 savedata/ 는 그대로 두면 그대로 이어서 쓴다.

   상시로 띄워 두려면 systemd 유닛에서 이 폴더를 WorkingDirectory 로 주고
   wfeature-server 를 ExecStart 로 잡으면 된다. 데몬용 옵션은 따로 없다.


6. 자주 막히는 곳

   - 방향키가 안 먹는 경우:
     - 키패드 위 Type1 버튼을 눌러 Type2 배치로 바꿔본다.
   - 포트가 이미 쓰이는 경우:
     - ./status.sh 로 누가 쓰는지 본다.
     - 예전 서버면 ./stop.sh 로 멈추고, 다른 프로그램이면 ./wfeature-server -addr :11542 처럼 포트를 바꿔 띄운다.
   - 목록에 게임이 안 보이는 경우:
     - 확장자가 .zip 또는 .jar 인지, games/ 아래 폴더에 들어 있는지 확인한다.
