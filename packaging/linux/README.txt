W-Feature — 피처폰 게임 에뮬레이터 (Linux)


1. 압축 풀기

   압축을 푼 폴더째 원하는 곳에 둔다.


2. 게임 넣기

   games 폴더 안에 게임 파일을 넣는다. 자세한 건 games/README.txt 문서 확인.


3. 실행

   압축을 푼 폴더에서 실행한다. 
   데스크톱 환경이면 잠시 뒤 브라우저에서 http://127.0.0.1:11541 이 열린다.

       ./start.sh

   ** 처음 막힐 수 있는 부분 **

   - 실행 권한이 없다는 경고:
     - 아카이브에서 권한이 떨어져 나간 경우 발생.

       chmod +x start.sh stop.sh status.sh wfeature-server

   - 브라우저가 자동으로 열리지 않는 경우:
     - SSH 같은 원격 접속이라 띄울 화면이 없어서 발생.
     - 위 주소를 직접 연다.

   서버를 멈추려면 Control-C 를 누른다.

   창을 이미 닫아버렸거나 예전에 띄운 서버가 남아 있으면 이 둘을 실행한다.

       ./status.sh              지금 떠 있는지, 몇 번 포트인지
       ./stop.sh                중지

   포트를 옮겨 띄웠으면 뒤에 포트를 붙인다 (./stop.sh 11542).


4. 접속

   서버는 http, https 두 주소를 함께 연다.
   게임패드를 사용하거나 음악이 밀릴 경우 https 주소로 접근해야한다.

       http://<IP>:11541        경고 없음. 음악이 밀릴 수 있고 게임패드 사용 불가능.
       https://<IP>:11641       첫 접속 때 인증서 경고 1회.

   IP: 서버 창의 "open from another device" 줄, 또는 ./status.sh 출력.
   예: http://192.168.0.1:11541, https://192.168.0.1:11641
   에뮬레이터 설정(키패드 배치, 음량 등)이 두 주소 간 공유되지 않는다.
   설정을 옮기려면 게임 선택 화면의 [백업] 기능을 사용한다.

   로컬호스트의 경우 http 접속이라도 음악이 밀리지 않고 게임패드 사용이 가능하다.

   ** https 첫 접속 경고 **

   - "연결이 비공개로 설정되어 있지 않습니다" 같은 경고:
     - 서버가 직접 만든 인증서여서 발생.
     - Chrome·Edge (PC, 안드로이드): [고급] → 아래의 "(안전하지 않음)" 링크
     - Firefox: [고급...] → [위험을 감수하고 계속]
     - Safari (Mac, iPhone): [세부사항 보기] → [이 웹 사이트 방문]. Mac은 확인 창과 암호 입력이 이어질 수 있다.

   ** 포트 바꾸기 **

   기본적으로 https 포트는 http 포트 + 100번으로 매핑된다.

       ./wfeature-server -addr :11542                http 11542, https 11642
       ./wfeature-server -https 11700                https 만 11700
       ./wfeature-server -https off                  https 끄기
       ./wfeature-server -addr 127.0.0.1:11541       로컬호스트에서만 허용

   기본 설정이면 같은 네트워크의 누구나 접속할 수 있다.
   브라우저에서 "홈 화면에 추가"를 하면 앱처럼 쓸 수 있다.


5. 폴더 구성

   wfeature-server              서버
   start.sh                     실행 스크립트
   stop.sh                      멈추기
   status.sh                    떠 있는지 확인
   games/                       게임을 넣는 곳
   ext/                         화면의 "＋ 게임 추가"로 넣은 게임
   savedata/                    세이브
   tls/                         https 인증서. 지우면 다음 실행 때 새로 만든다.
   logs/                        디버그 기록 (디버그 빌드에서만 생김)

   서버를 업데이트할 때는 wfeature-server 만 새 버전의 파일로 교체한다. 


6. 자주 막히는 곳

   - 방향키가 안 먹는 경우:
     - 키패드 타입을 바꾸거나 커스텀한다.
   - 포트가 이미 쓰이는 경우:
     - ./status.sh 로 wfeature 서버인지 다른 프로그램인지 본다.
     - ./stop.sh 로 멈추고 포트를 바꿔 띄운다.
   - https 주소만 안 열리는 경우:
     - 서버 창에 "serving without HTTPS" 가 있으면 해당 포트를 다른 프로세스가 점유 중.
     - https 포트를 다른 포트로 옮긴다.
   - 목록에 게임이 안 보이는 경우:
     - 확장자가 .zip 또는 .jar 인지, games/ 또는 그 바로 아래 폴더에 들어 있는지 확인한다.
