W-Feature — 피처폰 게임 에뮬레이터 (Linux)


1. 압축 풀기

   압축을 푼 폴더째 원하는 곳에 둔다.


2. 게임 넣기

   games 폴더 안에 게임 파일을 넣는다. 자세한 건 games/README.txt 문서 확인.


3. 실행

   압축을 푼 폴더에서 실행한다. 
   데스크톱 환경이면 잠시 뒤 브라우저에서 http://127.0.0.1:11541 이 열린다.

       ./start.sh

   ** 처음 막힐 수 있는 부분 **

   - 실행 권한이 없다는 경고:
     - 아카이브에서 권한이 떨어져 나간 경우 발생.

       chmod +x start.sh stop.sh status.sh wfeature-server

   - 브라우저가 자동으로 열리지 않는 경우:
     - SSH 같은 원격 접속이라 띄울 화면이 없어서 발생.
     - 위 주소를 직접 연다.

   서버를 멈추려면 Control-C 를 누른다.

   창을 이미 닫아버렸거나 예전에 띄운 서버가 남아 있으면 이 둘을 실행한다.

       ./status.sh              지금 떠 있는지, 몇 번 포트인지
       ./stop.sh                중지

   포트를 옮겨 띄웠으면 뒤에 포트를 붙인다 (./stop.sh 11542).


4. 휴대폰으로 접속

   같은 네트워크에 있는 폰의 브라우저에서 IP를 호출한다.
   예: http://192.168.0.1:11541

   이 컴퓨터에서만 쓰려면 이렇게 띄운다.

       ./wfeature-server -addr 127.0.0.1:11541

   브라우저에서 "홈 화면에 추가"를 하면 앱처럼 쓸 수 있다.


5. 폴더 구성

   wfeature-server              서버
   start.sh                     실행 스크립트
   stop.sh                      멈추기
   status.sh                    떠 있는지 확인
   games/                       게임을 넣는 곳
   ext/                         화면의 "＋ 게임 추가"로 넣은 게임
   savedata/                    세이브
   logs/                        디버그 기록 (디버그 빌드에서만 생김)

   서버를 업데이트할 때는 wfeature-server 만 새 버전의 파일로 교체한다. 


6. 자주 막히는 곳

   - 방향키가 안 먹는 경우:
     - 키패드 타입을 바꾸거나 커스텀한다.
   - 포트가 이미 쓰이는 경우:
     - ./status.sh 로 wfeature 서버인지 다른 프로그램인지 본다.
     - 예전 서버면 ./stop.sh 로 멈추고 다른 프로그램이면 ./wfeature-server -addr :11542 처럼 포트를 바꿔 띄운다.
   - 목록에 게임이 안 보이는 경우:
     - 확장자가 .zip 또는 .jar 인지, games/ 또는 그 바로 아래 폴더에 들어 있는지 확인한다.
